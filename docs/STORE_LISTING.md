## Full description (4000 chars max)
```
Gasolina MX te muestra las estaciones de servicio más cercanas a tu ubicación ordenadas por precio, usando los datos oficiales de la Comisión Nacional de Energía (CNE/CRE) actualizados cada 30 minutos.

¿Cómo funciona?
• Abre la app y permite el acceso a tu ubicación
• El mapa muestra las gasolineras cercanas con etiquetas de precio en colores:
  🟢 Verde = más barato
  🟡 Amarillo = precio intermedio
  🔴 Rojo = más caro
• Toca cualquier estación para ver los precios de Regular, Premium y Diesel
• Toca "Navegar" para ir directo a Google Maps con navegación paso a paso

Características principales:
✓ Mapa en tiempo real con precios color-codificados
✓ Filtra por tipo de combustible: Regular, Premium o Diesel
✓ Muestra Top 5, 10, 25 o 50 estaciones más cercanas
✓ Mueve el mapa para explorar precios en cualquier parte de México
✓ Tu posición se actualiza en tiempo real mientras te desplazas
✓ Reporta precios inconsistentes a PROFECO con un toque
✓ Ruta exacta con tiempo y distancia en auto
✓ Apertura directa en Google Maps para navegación
✓ Datos oficiales del gobierno mexicano (CNE/CRE)
✓ Inicio de sesión seguro con tu cuenta Google

Datos oficiales y confiables
Los precios provienen del portal público de la Comisión Nacional de Energía (CNE) y se actualizan automáticamente dos veces por hora. Nunca más pagues de más por la gasolina.

Privacidad
Solo usamos tu ubicación para mostrarte las estaciones más cercanas. Iniciamos sesión con Google únicamente para proteger el servicio y mantener los costos accesibles para todos los usuarios.
```
